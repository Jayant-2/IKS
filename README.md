🌌 IKS Explorer AI

Exploring India's Ancient Wisdom Through Modern Technology

IKS Explorer AI is an interactive educational web project designed to help people explore the rich heritage, ancient knowledge, culture, philosophy, and scientific contributions of India through a modern digital experience.

🌐 Live Website: https://iks-explorer-ai.ai.studio
💻 GitHub Repository: https://github.com/Jayant-2/IKS

---

📖 About the Project

India has a rich legacy of knowledge spanning mathematics, astronomy, philosophy, architecture, medicine, literature, and more.

IKS Explorer AI aims to make this knowledge more accessible through an engaging web experience that connects India's traditional wisdom with modern technology.

Our vision is to encourage students and curious learners to discover, understand, and appreciate the Indian Knowledge System.

✨ Key Features

- 🇮🇳 Explore India's knowledge heritage
- 🌌 Modern, immersive visual experience
- 📚 Educational exploration of Indian traditions and knowledge
- 🤖 AI-oriented learning experience
- 🎨 Modern and engaging user interface
- 📱 Responsive design, where supported
- 🚀 Accessible through a web browser

Features should be adjusted to match the functionality currently implemented in the website.

🎯 Project Objectives

- Promote awareness of the Indian Knowledge System.
- Make traditional knowledge more accessible to learners.
- Combine educational content with modern web technology.
- Create an engaging digital learning experience.
- Encourage exploration of India's cultural and intellectual heritage.

⚙️ Run Locally

Prerequisites

Install the following tools:

- "Node.js" (https://nodejs.org/)
- "Git" (https://git-scm.com/)

Step 1: Clone the Repository

git clone https://github.com/Jayant-2/IKS.git

Step 2: Open the Project Folder

cd IKS

Step 3: Install Dependencies

npm install

Step 4: Start the Development Server

npm run dev

Step 5: Open the Website

Open the local URL displayed in your terminal, usually:

http://localhost:5173
